# 台股型態學技術分析教學技能

本技能整理自「朱家紅老師型態直播班」與「林穎老師型態圖形班」課程內容的方法論摘要（來源：使用者的 NotebookLM 筆記本，已用自己的話重新整理，非逐字引用）。用途是讓 Claude 在做選股建議、型態判讀、持股診斷、盤後分析、週走圖報表時，能貼近兩位老師一貫的分析邏輯與紀律風格。

**重要提醒**：這是教學方法論的重整，僅供分析框架參考，不構成投資建議。任何實際操作建議都應提醒使用者這只是技術面框架，不是保證獲利的公式。

## 核心哲學（兩位老師共通點）

1. **紀律優先於預測**：型態學是機率統計工具，不是絕對預言。進場前要有完整計畫，進場後嚴格執行 SOP，不摻雜個人情感或消息面。
2. **大盤決定積極度**：個股永遠在大盤的脈絡裡操作。大盤多頭時可提高資金部位、抱波段；大盤走弱或空頭時，只能做短線、資金部位大幅降低，跌破關鍵均線就出場。
3. **位置決定策略**：股價相對於均線（尤其月線）的位置，決定該用什麼策略應對，而不是看基本面好壞。
4. **股票沒有好壞，只有多空**：不對特定標的產生感情，只有「做多 / 做空 / 不做」三種選擇。

### `references/pattern_recognition.md` — 型態辨識
- 底部反轉型態：頭肩底（頸線＝左右肩反彈高點連線，右肩不可跌破中心低點到反彈高點一半，需帶量突破頸線）、W底（建議等回測頸線不破再進場，勝率較高）、N字底（第二次探底高於第一次）、圓弧底、下降楔形、三重底/箱型整理、喇叭型擴張底。
- 頭部型態與底部型態邏輯鏡像對稱（M頭、頭肩頂）。
- 中繼型態（旗形/三角形收斂）成功率通常高於反轉型態；理想突破位置約在收斂區間長度75%–80%處。
- 型態驗證鐵律：突破頸線/壓力線當天須實體紅K＋放量，否則視為假突破；「關前放大量卻未突破」代表賣壓沉重。
- 四線多排（5/10/20/60日均線由上而下排列且上揚）代表多頭趨勢強勁，型態在月線正上揚處突破成功率更高。
- **需要細節時讀取全文**：判斷某檔股票具體是哪種型態、要看對稱性/量能細節時。

### `references/entry_exit_rules.md` — 進出場規則與資金管理
- 朱家紅老師三段式進場：試單點（型態近完成）→確認點（突破頸線）→加碼點（回測不破）。
- 林穎老師二分法：多頭「回後買上漲」（回檔不破前低＋紅K站回5日均線）／空頭「彈後空下跌」（反彈不破前高＋黑K跌破5日均線）。
- 停損三法可搭配使用：K線停損（守進場當根低點或前轉折低點）、百分比停損（5%–7%）、趨勢停損（頭部走低絕對出場，不論盈虧）。
- 目標價估算：等幅測量法（頸線到低點價差往上加計）、N字測量法（AB=CD，前一波漲幅往上加計）。
- 資金部位隨大盤動態調整（多頭7–8成／盤整轉弱降到4成以下），不攤平（除非歷史低檔分批布局，最多三次）。
- 三指標背離（價/量/KD/MACD不同步）是反轉先期訊號。
- **需要細節時讀取全文**：要給出具體停損價位、目標價計算、或資金配置建議時。

### `references/trading_discipline_series.md` — 交易守則01-36 ＋ 趨勢轉折研究
- 切線角度是趨勢強度量尺；切線壓力/支撐作用遞減（第一次觸碰最易受阻，第二次約打對折，第三次以後易被穿越）。
- 飆股操作需要「技術判斷力＋敢不敢狠不狠的執行力」；三種加碼時機＝回後買上漲／突破長黑高點／盤整突破；前提通常是2-3個月以上底部整理＋帶量突破頸線。
- 均線功能三部曲（趨勢線/支撐線/壓力線）；魚身理論：魚頭（突破均線）進場，魚身（沿均線上漲）續抱，魚尾（跌破均線回檔）不追。
- 停利依操作週期不同（當沖2-3%／短線5-8%／中期20-30%／長期40-80%），停利是反人性行為，應在進場前就規劃好。
- 資金比例隨大盤走勢動態調整；長線機會看週線型態＋吸貨量＋大盤/類股/個股三方同步轉強。
- 基本面/消息面須用股價走勢驗證（利多不漲反跌＝藉利多出貨；利空不跌反漲＝藉利空洗盤），不可違反技術面紀律。
- **需要細節時讀取全文**：需要飆股操作SOP細節、均線交易法的具體條件組合、或資金管理數字時。

### `references/stock_selection_series.md` — 選股守則01-20
- 看圖選股七步驟：趨勢確認（頭頭高底底高）→均線多排→站上月線→判斷所處位置→評估壓力支撐→評估勝率與獲利率→綜合決策。
- 葛蘭碧八大法則：做多/做空各4個訊號，均線由下降轉平緩＋股價突破＝反轉訊號；乖離過大反彈/回檔向均線靠近為逆勢訊號（風險較高）。
- 六大指標速查：KD（黃金/死亡交叉需搭配趨勢判讀，80以上/20以下易鈍化，背離判斷反轉）、MACD（0軸上下決定多空格局，柱狀體背離）、RSI（逆勢指標，>80超買<20超賣）、乖離率/MA通道（正乖離過大有回檔壓力）、ADL（與大盤同步/背離判斷趨勢延續或反轉）、布林通道（8個買賣訊號，三軌收斂後放量突破會重新張口）。
- 支撐壓力角色會互換：轉折高點突破後轉為支撐、未突破前是壓力（反之亦然）；密集盤整區時間越長量越大，支撐/壓力越強。
- **需要細節時讀取全文**：要具體套用某個指標的公式、判斷鈍化/背離細節、或支撐壓力位置估算時。

### `references/volume_price_relationships.md` — 量價關係九宮格
- 核心框架：價（漲/跌/平）× 量（增/縮/平）＝九種組合，但同一組合在「底部」和「高檔」代表意義往往相反，須疊加「目前位置」判讀。
- 量能分級與定義：基本量（5日均量）、攻擊量（基本量1.2-1.3倍以上）、止跌量、進貨量、換手量（成功續漲）／出貨量（換手失敗或高檔開高走低收黑）。
- 判斷換手成功的關鍵價位：大量K線最高點（突破＝換手成功）、1/2價（未破＝洗盤）、最低點（跌破＝換手失敗轉出貨量）。
- **需要細節時讀取全文**：要判斷某天K線的價量組合在特定位置代表什麼意義時（九種組合逐一列有位置對照表）。

### `references/gap_theory.md` — 缺口理論
- 核心觀念：缺口力量大於K線力量；缺口位置（打底完成/上漲行進中/末升段竭盡等）決定意義，同樣是向上缺口意義可能天差地遠。
- 向上6種情境／向下5種情境互為鏡像；底部打底完成的突破缺口需大量配合，末升段竭盡缺口則是爆量後隨即量縮價漲乏力。
- 缺口形成四個關鍵支撐/壓力價位（由強至弱：上高價>上沿價>下沿價>下底價，向下對稱）。
- 真封口（大量實體K線收盤真正回補，支撐/壓力特性消失）vs 假封口（長影線/量縮/量能不符，行情易延續原方向）；三天內回補常視為假突破/假跌破。
- **需要細節時讀取全文**：要判斷某個缺口屬於哪種情境、或缺口支撐壓力價位的具體估算時。

## 資料庫來源（重要）

台股日K/技術指標資料庫由使用者在本機執行 `tw-stock-db` 爬蟲產生，並自動同步到 GitHub repository：

```
https://github.com/sunneo/tw_stock_db
```

該 repo 自己也有一份 SKILL.md（`main` 分支根目錄）詳細說明資料結構，此處摘要對齊後的重點：

### 分支結構

- **`main` 分支 — 逐日增量資料（每個交易日更新一次）**
  路徑：`daily/{日期}/`（例如 `daily/2026-07-24/`），每個資料夾內有 4 個 CSV：
  `stocks.csv`（當天股票基本清單，全量）、`daily_prices.csv`（當天全部個股OHLCV）、
  `technical_indicators.csv`（當天全部個股技術指標）、`market_index.csv`（大盤/櫃買指數）。
  每個 CSV 可直接用 `raw.githubusercontent.com/sunneo/tw_stock_db/main/daily/{日期}/{檔名}.csv`
  抓取，欄位與 `tw-stock-db` 的 schema 完全對應。**只需要最近幾天資料時，優先用這個分支**，
  不用整包 clone。

- **`db-snapshot` 分支 — 完整資料庫快照（每月覆蓋一次，不留歷史）**
  內容為 `tw_stock.db` 切成 **5 個 64MB 以內的 part 檔**（`tw_stock.db.part000` ~ `part004`），
  **不使用 Git LFS**（早期版本曾用 LFS，因免費頻寬額度僅 1GB/月太容易超額，已改為一般
  git 檔案 + 切割方式），另附 `merge_db.py`（純 Python 標準函式庫）與
  `tw_stock.db.manifest.json`（記錄 sha256 checksum）。

  取得完整資料庫的正確流程：
  ```bash
  git clone --branch db-snapshot --single-branch --depth 1 https://github.com/sunneo/tw_stock_db.git
  cd tw_stock_db
  python merge_db.py     # 合併 part 檔並自動核對 sha256 checksum
  ```
  合併後即為完整 `tw_stock.db`（約2年歷史，含近2年 daily_prices / technical_indicators）。
  **此流程已實際測試成功**（clone + merge + checksum 驗證通過，資料庫可正常查詢）。
  這個分支**只在需要完整歷史（例如長天期均線、回測）時才 clone**，平常分析用 `main`
  分支的每日 CSV 即可，避免不必要的頻寬與時間成本。

### 資料時效判斷規則（固定條件，每次分析前必須先檢查）

- **每日 12:10 之後**的查詢，若當天 GitHub `daily/{今天日期}/` 尚未更新（通常盤後才會更新），應將當下能取得的最新報價視為「**盤中資料**」，並在回覆中明確標註「此為盤中參考數據，非正式收盤價」，不可當作正式收盤資料用於型態確認、進出場訊號判斷。
- **每日 17:10 之後**，台股當天收盤資料應已透過 `tw-stock-db` 爬蟲同步上 GitHub，此時起**必須改用「當天」的正式收盤資料**重新查詢與分析，不可再沿用前一交易日的舊資料；若當天 `daily/{今天日期}/` 仍抓不到，才特別註明「今日資料尚未更新，以下為最近一個交易日資料」。
- 這條規則優先於「每日節奏 vs 每週節奏」判斷：先確認現在是幾點、資料庫最新日期是哪天，再決定要不要重新抓資料，避免誤用過期或未收盤資料做結論。

### 使用建議（依任務類型選擇資料來源）

- 選股 / 鎖股名單 / 最近幾天的持股追蹤 → 讀 `main` 分支 `daily/{最近幾天日期}/*.csv`
- 需要完整歷史（回測、長天期均線、季線判斷等） → clone `db-snapshot` 分支 + `merge_db.py`
- 每次分析前先確認資料的最新交易日期，避免使用過期快照
- 若 GitHub 當下抓不到、或找不到對應日期的資料，才退回請使用者手動上傳 `tw_stock.db`

### 已知限制（資料來源相關）

- 資料源為 Yahoo Finance，法人買賣超/融資融券等籌碼面資料尚未納入。
- `db-snapshot` 分支每月被 force push 覆蓋，不要依賴其 commit 歷史，只信任最新一次 commit。
- 少數股票（例如 6174、8111）因公司名稱含 Big5/CP950 無法解碼的罕見字，`stock_name`

- 美股觀察指標同樣來自 Yahoo Finance，若當下抓不到（API 異常/尚未收盤），不可阻斷台股本身
  的分析，只需在回覆中註明「美股資料暫缺，以下大盤判斷僅依台股本身指標」。

## 美股觀察指標與台股連動判讀

`market_index` 資料表除了 `TAIEX`（加權指數）、`TPEx`（櫃買指數），現在也包含三個美股觀察
指標（同一張表，`index_code` 分別為 `SOX`／`SPX`／`NASDAQ`，由 `scrapers/fetch_market_index.py`
一併抓取；`analysis/generate_daily_report.py` 的「大盤環境」段落已自動列出）：

| index_code | 指數 | Ticker | 角色 |
|---|---|---|---|
| `SOX` | 費城半導體指數 | `^SOX` | 與台股半導體供應鏈（台積電、聯發科、日月光、聯電等）連動性最高的領先指標 |
| `SPX` | 標普500 | `^GSPC` | 美股大盤整體 risk-on/risk-off 氣氛，影響外資對台股等新興市場的資金流向 |
| `NASDAQ` | 那斯達克綜合指數 | `^IXIC` | 全球科技股（AI/雲端/軟體）風險偏好，對電子/AI概念股（廣達、緯創等）有次於SOX的參考性 |

### 時區換算（判讀順序的關鍵）

美股交易時間為美東 9:30–16:00，換算台灣時間約為 **21:30（夏令）／22:30（冬令）～ 隔日
04:00／05:00**。也就是說，**台股開盤前（09:00）看到的美股收盤資料，一定是「前一晚」的
結果**，是台股當天開盤情緒的領先指標，而不是同步資料。分析台股當天走勢前，應先確認
`market_index` 裡 `SOX`/`SPX`/`NASDAQ` 最新一筆 `trade_date` 是否為「前一個美股交易日」，
避免誤用更早的舊資料當作「隔夜美股」。

### 用於大盤積極度判斷（呼應核心哲學2「大盤決定積極度」）

在原本「台股大盤多空排列（四線多排/空排、月線季線位置）」的基礎上，把隔夜美股方向當作
**領先確認或背離訊號**，不是獨立判斷依據：

- **美股同步收紅**（SOX/NASDAQ/SPX 同向上漲，尤其 SOX）＋ 台股原本站上月線、多排 →
  積極度可維持或提高，屬於順風環境。
- **美股同步重挫**（尤其 SOX 單日跌幅明顯、或跌破其月線MA20）→ 即使台股原本多排，當天
  也應**降低積極度**：新倉位觀望為主，既有部位留意跳空開低風險，優先檢查是否觸及防守點。
- **美股與台股走勢背離**（例如美股大漲但台股開高走低、或美股重挫但台股逆勢抗跌）→ 視為
  警訊而非利多/利空的簡單相加，可能是外資調節、內資獨立行情、或消息面時間差，需要**更
  嚴格執行停損紀律**，不可用「美股很強」合理化凹單續抱已跌破防守點的部位。

### 用於個股進場時機微調（尤其半導體/電子權值股）

- 半導體/電子權值股（尤其 SOX 成分股的台灣供應鏈，如台積電、聯發科、日月光、聯電）在
  型態符合 `references/entry_exit_rules.md` 的進場條件時：
  - 若同時 SOX 同步轉強（站上其MA20、且近5日走勢向上）→ 可視為**加分確認**（confirmation），
    維持原訂的三段式或二分法進場節奏即可。
  - 若同時 SOX 同步轉弱 → 即使個股型態進場訊號成立，建議**降低試單部位**，優先採用「確認點」
    （已突破頸線）而非「試單點」（型態近完成）進場，不宜第一時間重倉。
- **停損紀律不因美股強弱而放寬**：美股大漲不是不停損的理由；美股走弱也不是提前恐慌出場
  已符合SOP續抱條件部位的理由。SOP／技術面紀律優先於消息面與隔夜美股情緒（呼應核心哲學1
  「紀律優先於預測」）。

### 用於情境 A/B/C 的實際做法

- **情境 A / C（大盤與型態判讀）**：判斷大盤位置前，先讀最新一筆 `SOX`/`SPX`/`NASDAQ`，
  用上面的規則決定當天積極度是「維持」「調降」還是「背離警訊」，再接原本的台股四線多排/
  空排判斷。
- **情境 B（持股診斷）**：若持股屬於半導體/電子供應鏈，診斷「續抱／減碼／出場／加碼」時，
  一併帶入 SOX 近況作為佐證（不是決定因素），並在回覆中註明是否有背離情況需要提醒使用者。

**重要提醒**：美股資訊是輔助判讀的領先/背離訊號，不是另一套獨立的進出場系統，最終決策仍
以台股本身的型態、量價、均線位置與 SOP 停損停利規則為主。

## 使用情境與工作流程

### 情境 A：型態判讀 / 選股邏輯說明
當使用者問「這是什麼型態」「這檔股票可以買嗎」等問題時：
1. 先確認目前股價位置（月線之上/之下、月線走勢方向），並讀取隔夜美股觀察指標（見上一節）
   判斷當天大盤積極度是否需要調整
2. 判斷所屬趨勢（頭頭高底底高＝多頭；頭頭低底底低＝空頭；盤整）
3. 對照 `references/pattern_recognition.md` 找出型態特徵是否吻合，並檢查量價關係是否驗證型態（例如突破頸線是否有效放量）
4. 依 `references/entry_exit_rules.md` 給出進場條件、停損點、目標價估算方式；若為半導體/電子權值股，套用上一節「個股進場時機微調」規則
5. 一律提醒：這是技術面框架推演，非投資建議，且需搭配大盤環境判斷積極度

### 情境 B：持股診斷 / 持股追蹤分析
1. 抓取個股近期日K資料與均線位置（見資料庫 schema，若已建置）
2. 判斷目前處於哪個階段：型態進行中 / 已突破未回測 / 已達目標價 / 已跌破防守點
3. 給出「續抱／減碼／出場／加碼」的技術面判斷理由，並附上對應的量價證據；半導體/電子供應鏈個股一併帶入 SOX 近況佐證
4. 同步檢視大盤位置（含隔夜美股方向），說明個股操作積極度是否該隨大盤調整

### 情境 C：盤後分析 / 週走圖報表
1. 大盤：先看隔夜美股觀察指標（SOX/SPX/NASDAQ）方向，再判斷台股多空排列（四線多排/空排）、是否跌破月線或季線，兩者合併給出當週/當日積極度結論
2. 類股輪動：找出當日/當週表現最強與最弱的類股，半導體/電子類股可對照 SOX 走勢
3. 個股掃描：篩選符合「回後買上漲」「盤整突破」等進場條件的標的清單
4. 產出圖文並茂的網頁簡報（HTML + 圖表），版面與敘事風格盡量貼近兩位老師「型態＋SOP分開標註」的教學邏輯：先講型態辨識（機率統計），再講紀律執行（SOP）
