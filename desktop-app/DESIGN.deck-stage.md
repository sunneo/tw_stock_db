# 簡報的動畫舞台（collage）、音效、疊字幕、故事→舞台

簡報的 `visual: { kind: collage }` 讓一頁像電玩場景：物件有位置與動畫，旁白一句一句帶出它們，音效連動，敘事文字打出來。

## 描述格式（deck_core.js）

座標與大小都用舞台矩形的比例（0～1，可超出 -1～2 讓物件從場外跑進來）。

- `items[]`：`src`（@imgN 或圖片目錄）、`x y w`、`at`（0＝一開始就在；`{sentence:N}`＝念到第 N 句時彈出）、`label`（名牌）、`ring`（圈／框）、`swing`（左右擺動 ±度）、`bob`（跳動）、`alpha`、`card:false`（不加貼紙底）、`keys[]`（關鍵影格：`at`＋`sec` 移動，到達時間為 `at`）、`say[]`（對話泡泡，`sentence`＋`text`）、`sfx`（`pop`／`move`／`say` 各綁一個音效名）、`scene`。
- `camera[]`：鏡頭 `zoom` 與中心，依時間內插（走進屋裡＝拉近、走出＝拉遠）。
- `scenes[]`：場景時間軸，轉場 `fade｜zoom｜cut`。
- `texts[]`：敘事文字（`typed` 逐字打出、`title`、`shout` 大字）。
- `sounds[]`：獨立音效（時間或句子）。音效名單 `SFX_NAMES`，由 `deck_sfx.js` 用程式合成（不需音檔），播放與匯出 MP4 都會混進去。
- 句子編號一律用 `splitSentences`，旁白、字幕、舞台共用同一份切法，所以「第 N 句彈出」一定對得上。

## 字幕與重點

- `deck.captions`：多軌疊字幕，中文在上、英文縮小在下（縮放 1／0.7／0.6）；`caption` 可給每頁單獨的另一軌。
- `deck.bullets`：`highlight`（預設）重點字先出現並亮起，再念；`legacy` 維持念完才出現。
- 開啟簡報包時，沒有音檔的頁保持靜音（`manualVoice`），🎙 面板可重做這頁、全部重做、重試失敗的頁、幫沒有音檔的頁生成。

## 故事→舞台（stage_core.js，意象推導＋CoLU）

流程完全符合 CoLU 的形狀：程式讀、封閉選單只在歧義時問、程式有預設退路、程式檢查。

1. `readStory`：用詞表（`LEX`，中英文名詞）找角色與地點、數量（「三隻小豬」＝3）、個別角色（豬大哥／二哥／小弟）；讀出誰說了什麼、動作（跑、吹、敲）、喊叫、走進／走出（只有動作本身才動鏡頭，「裡面住著」只是描述地點）。
2. `planStage`：排成 collage（地點當背景、角色在第一次被提到的句子彈出、台詞變泡泡、跑的動作從場外進來並綁腳步聲、吹＝風聲）。
3. 說話的人認不出來：產生封閉問題（選項＝出場的角色，附程式預設）。`planStageAsync` 可交給小模型選字母，選錯或失敗就用預設。
4. `introList`：名詞清單（「認識：蜘蛛、猴子、蝴蝶」）→「這是蜘蛛。這是猴子。」每個彈出、圈起來、擺動、有名牌。
5. 內建故事 `STORIES`（三隻小豬、龜兔賽跑）；認不得角色就回報「沒有認得的角色」，不編造圖。
6. 宿主（floating-assistant.js）的 `deck_from_story` 食譜：先取故事文字／故事名稱／名詞清單，用 emoji 畫成圖片放進圖片目錄，再交給 `render_presentation`。沒有材料時整條食譜失敗，橋接層會回頭向使用者要材料。某些 emoji 在舊系統畫不出來（顯示成空框），畫之前先偵測，改用 `ALT` 裡的替代圖。
