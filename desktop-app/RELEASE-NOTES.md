# 桌面版更新內容（2026-09-15 第一個 commit ～ 2026-10-09）

從把浮動 AI 助理包成桌面版開始，到現在共 329 個 commit。版本號依序是 0.1.0（第一版）→ 0.2.0（2026-09-29）→ 0.3.0／0.3.1／0.3.2（2026-09-30）；之後的改動都以「即時更新」方式發佈，安裝檔的版本號沒有再變。

## 新功能：動畫簡報（`/media-presentation`）

一句話（或給檔案、授權資料夾、網站、程式碼 patch）就能得到一份動畫簡報，在對話裡直接播放：

- **內容**：章節與投影片；每頁有標題、要點、旁白（文字轉語音，底部字幕）、轉場；視覺可以是自己畫的 2D 動畫、表格、圖片（可圈出重點）、流程圖、圖表、2D 與 3D 混合（3D 模型加鏡頭運鏡）、並排版面。
- **互動**：可捲動且有語法上色的程式碼與 patch 視窗、嵌在簡報裡的真終端機、問答卡（單選、多選、簡答、問答題由 AI 評分、實作題）、**AI 自己寫的小遊戲**（例如打磚塊，跑在沙盒裡，只能回報分數）。
- **長簡報**：AI 分批寫（最長約 75 分鐘），仍然是一份簡報。
- **匯出**：MP4（含旁白與字幕）、PPTX、原始描述檔、字幕、簡報封包（`.deckpack`，含作答紀錄，可用 `/media-open-presentation`、拖進對話或當附件再開啟）。
- **來源**：上傳的檔案、授權資料夾、網站、專案索引，或只給主題。
- 匯出時取消會立刻生效；已預熱的頁不會重做；中文旁白可以同時合成多段。
- 預設樣板沒有品牌圖片；顏色、字型、版面可以用設定裡的 `deckTemplate` 覆寫（還沒有編輯介面）。
- 內建技能：`media-presentation`；斜線指令：`/media-presentation`、`/media-open-presentation`。

## 這個版本的重點

- **專案索引（AIDoc）**：大型專案（例如建置後 50 萬檔的 OpenBMC）不再把整張地圖放進記憶體，索引直接寫進專案資料夾裡的 SQLite 檔；桌面版與網頁版都是；檔案數量與大小預設不設上限。
- **SQLite 工具集**：終端機的 `sqlite3`、`sqlitebrowser` 瀏覽視窗、Python 橋接、`repo_sql`，桌面版用 node:sqlite，網頁版用 sqlite-wasm。
- **終端機 `/mnt` 即時對應**：授權資料夾直接當真的檔案系統用，不再複製；寫入延後合併、`sync` 時強制寫回。
- **離線能力**：離線訓練器、離線圖像轉文字、離線文字模型、離線小模型食譜、離線多步驟計畫。
- **YouTube 下載、影片剪輯、PDF／圖片工具、2D 動畫與 3D 場景檢視器**。
- **多對話並行背景執行**、左邊對話清單、台灣節慶套版。
- **即時更新（Live Update）**：不用重新安裝就能收到介面程式的修正。

## 需要重新安裝才會生效的部分

介面程式（`floating-assistant.js`、`index.html`、`bootstrap.js`）可以用即時更新取得。以下是主程式的改動，需要安裝新的安裝檔，或讓即時更新下載後重新啟動：

- 0.3.0 起：主行程模組納入即時更新白名單、啟動時優先載入覆蓋版本（舊安裝檔要先換一次新安裝檔，之後才吃得到）。
- 外部 http(s) 連結改交給系統瀏覽器開（2026-10-03）。
- SQLite 引擎（`sqlite-engine.js`）、終端機 `/mnt` 即時對應（`fsx-sync.js`）、Windows 上寫回被占用檔案的修正（2026-10-08）。

## 桌面版本身

- 用 Electron 打包，內建自訂圖示；Windows 有真正的安裝程式（NSIS），也保留免安裝資料夾；Electron 由 31 升到 44（終端機的 busybox 需要較新的瀏覽器核心）。
- **指令列模式**：`-p '提示'` 非互動執行，支援 `--output-format`；Windows 附 `FloatingAssistant-cli.exe` 啟動器。
- **本機 proxy**：每次啟動自動挑空的連接埠；不再硬性要求外部服務；可選「不開連接埠」的內嵌模式；網路搜尋改在本機實作（含備援網址）；中文語音（edge-tts）在本機實作；修正每次重啟後連不上的問題。
- **真實檔案與命令**：不受限的檔案工具、`run_command` 有真正的 shell（bash／Git Bash／PowerShell）、tmux 工具、大型檔案分段讀取與逐段彙整、批次處理工具。
- **內建 API 金鑰**（新使用者免設定，可被自己的覆蓋）；預設模型換成 nemotron-3-ultra-550b-a55b，模型下架（410）自動換下一筆。
- **即時更新**：右上角「檢查更新」，依檔案比對、驗證 md5（相容 Windows 與 Linux 的換行差異）、顯示真實版本號與更新說明；多份 AppImage 並存時的版本仲裁。
- 拖曳檔案進畫面變成附件、拖進終端機直接複製進沙盒；聊天輸入框可貼上剪貼簿的圖片與檔案。
- 設定頁分組（AI／多媒體／桌面程式單機／檔案存取），檔案存取與 Git 自成一組。

## 終端機（`/run-terminal`）

- 嵌在對話裡的 xterm 終端機，真正的 busybox shell；內建 less／more／vi／vim／top／python／jq／curl／wget／httping／m4／make 等；`ask-floating-ai-assistant` 可以在終端機裡叫 AI。
- 自己寫的 shell 語法分析與非同步執行器：控制流程、函式、`export` 持久化、特殊變數、here document、多行貼上、續行提示。
- 授權資料夾掛在 `/mnt/<名稱>`；檔案傳輸視窗（兩欄、可排序、可調欄寬、聊天／授權資料夾／工作目錄／電腦↔沙盒）。
- 終端機可視窗化（拖曳、調整大小、全螢幕）、外觀可一次套用到全部、右鍵選單、PPTX／PDF 匯出、重新整理後還原畫面。
- 給 AI 的終端機工具：用編號或名稱定址、執行並取得離開碼、讀螢幕文字、複製檔案進出。
- **新：`/mnt` 改成即時對應真實資料夾**（不複製）：目錄與檔案資訊快取、區塊讀取、延後寫入、`sync` 強制寫回、衝突偵測，桌面版與網頁版都有。
- Python 執行：`subprocess`、`urllib`、多行程（用 Web Worker 模擬）等橋接。

## 子任務領域與技能

- 研究（唯讀）、程式設計（平行／HPC／網路服務／繪圖／嵌入式／BMC／Android／Windows／iOS／BIOS-UEFI-EDK II 等 10 多個專長與流程狀態）、辦公室報告、檔案分析、媒體、技能製作、瀏覽器控制等領域；領域管理介面（新增、編輯、AI 修訂、乾跑）。
- 內建技能機制：skill-creator、image-redraw；匯入／執行技能包的規範（先讀懂腳本、優先用助理自己的工具、中文路徑與輸出不亂碼）。
- **技能包的 Python API 轉接層**：執行技能包腳本時，`playwright`、`openai`、`anthropic`、`websocket` 等公開介面實際接到助理的工具與目前選用的模型。
- 子任務用完回合會回報進度；可摺疊的逐步紀錄（思考、工具呼叫、結果）；模型把工具呼叫寫成文字 JSON 時也能執行；同樣的呼叫重複出現會提醒用上次結果。
- 「宣稱已建立檔案」會直接用磁碟驗證，不存在就退回重做。
- 程式設計領域：以補丁為單位的修改流程、暫存工作區（複製一份、git init、驗證後才部署回去）、`fap_apply_patch`、`attachment_apply_patch`。

## 瀏覽器控制

- Chrome 擴充功能＋本機橋接伺服器：單一「AI 控制」分頁群組、分頁自動恢復與自動啟動、不搶焦點、回合結束自動關分頁、依選擇器或文字點擊、下載追蹤、結構化讀取頁面（分段讀長文、圖文穿插）、截圖支援框選範圍與讓 AI 看圖。
- 網路搜尋：多個來源，本機實作，不需要 Cloudflare。

## 專案索引（AIDoc）、行為分析與 SQLite

- **AIDoc**（原 DeepWiki，舊名保留）：背景漸進建索引（進度卡片、可停止／接續）、`repo_map`／`repo_ask`／`repo_wiki`、AI 補說明（Markdown 編輯器）、檢視器（左中右可拖曳版面、`檔案:行號` 連結嵌入程式碼視窗）、匯出 SQLite 與問答網頁。
- **新：索引改寫進專案資料夾的 SQLite**（`.floating-assistant/index/`，自動加 `.gitignore`）；全文索引、符號表、引用關係；查詢記憶體用量固定；桌面版與網頁版（OPFS 建庫、串流複製進專案資料夾、唯讀虛擬檔案系統查詢）都支援；沒有檔案數量與大小上限。
- 已建置的 OpenBMC／Yocto 專案：自動略過建置輸出與下載快取，保留原始碼樹。
- **程式行為分析**：語法樹掃描、逐行追蹤、呼叫圖、資料流；x86／x64／PTX／JVM／LLVM／WASM／Python 位元組碼指令表；POSIX／WinAPI／GLSL 等 API 語意；`explain_code`、`/aidoc explain`。
- **SQLite 工具集**：`sqlite3` 指令（輸出模式、點指令、REPL）、`sqlitebrowser` 浮動視窗（結構、瀏覽與過濾、編輯、執行 SQL、Pragma）、Python 的 `fa_sqlite`、`fap:` 直接對應真實檔案、唯讀的 `repo_sql`；只檢視不再把資料庫寫回來源。

## 離線能力

- **離線訓練器**：離線語意核心、右上角線上／離線開關、乾跑、多步驟做法、狀態機、原始碼工具（沙盒 Worker）、可匯出匯入的資料包（含版本檢查）；`/offline-trainer-by-ai` 讓線上 AI 當老師教它。
- **離線圖像轉文字**：Florence-2、SmolVLM、ViT-GPT2、LLaVA-Interleave（附實測結果）；抽象的圖像介面（線上優先／離線優先／只線上／只離線）。
- **離線文字模型**：模型清單、角色與優先順序、GPU／CPU 分派、工具呼叫基準測試；**小模型食譜**（程式路由與填欄位，模型只做選擇題與填空題，每步驗證、留決策紀錄）；**多步驟計畫**（目標→階段→步驟，狀態機＋決策樹）。
- **自己學格式**：日誌格式、設定檔結構（INI／TOML／EDK II 各種檔）、文法自己發現（含遞迴文法與 LALR(1) 分析表）、語法斷點發現、混合內容的語法高亮、英文句子與意圖推導。
- **參考知識**：Linux／Windows 錯誤碼、gcc／gdb／qemu 等命令手冊、建置與核心日誌約 200 條診斷規則（含多行的堆疊追蹤）、C++ 標準函式庫／Rust／Go 名稱表。
- **UML → 程式骨架**、設計檢視器、互動對話卡片（表單／wizard）、知識類型註冊表（含版本遷移、備份還原）。

## 多媒體與文件

- **影片**：擷取片段（含純聲音）、轉 GIF、轉 2D 動畫、指定時間截幀、配音、合併音檔、燒入字幕、語音轉文字。
- **文字轉語音**：英文用本機 Kokoro，中文用語音轉接；可調語速。
- **YouTube 下載**：在瀏覽器裡跑 yt-dlp（含簽章解密與 PO Token 橋接）、影音分開時自動合併、分段下載、進度與剩餘時間、驗證範圍可選（自己的頻道或授權影片）；yt-dlp 版本釘住並有自我檢查。
- **PDF 與圖片**：合併、刪頁、抽頁、抽圖、密碼保護、圖片轉 PDF、PDF／圖片檢視器、圖片解讀（自動挑支援讀圖的模型）、多圖比較、投影片抽圖。
- **PPTX 匯出**：文字不再溢出重疊、表格跨頁重複表頭、圖片依長寬比選版面。
- **2D 動畫檢視器**：縮放／平移／聚焦、鏡頭、漸層、緩動曲線；**3D 場景檢視器**；各檢視器點過才吃滾輪；UML／流程圖縮放改向量重繪。
- **圖像標註**（魔術棒、畫框、文字框）、**蒙皮動畫檢視器**、`image-decompose-redraw` 技能（把一張圖分解成 2.5D 並產生 3D 檢視資料）。
- **沙盒模擬後端**：fetch／WebSocket／XMLHttpRequest／EventSource 接到持久儲存的 Worker 伺服器，可匯出成 Node 或 Cloudflare 部署檔。

## 對話介面

- 左邊對話清單：可收合、可調寬、可分群組；順序依建立時間固定。
- **多對話並行背景執行**：AI 執行中可以切到別的對話，清單顯示沙漏與未讀，切回來看得到進行中的內容；斜線指令也綁定在送出的對話。
- 台灣節慶套版：依台灣行事曆自動換裝。
- 建議操作（`/suggest`）：快速開始＋分類可展開；AI 功能清冊與說明子代理人；功能範例可直接「▶ 送出」。
- 匯出對話含思考與工具呼叫紀錄（Markdown／JSON）；斜線指令也記進輸入框的上下鍵歷史。
- 亮色主題下的外觀修正；輸入法不再被打斷。

## 穩定性與修正（節錄）

- 修正 `-p` 模式在 Windows 輸出遺失、封裝後缺檔當機、更新套用時的檔案路徑錯誤。
- 修正模型被截斷或重複攔截時卡住、說要做卻沒做就停止、話題轉移誤判、壓縮摘要遺失已成功的工具紀錄。
- 修正 Windows 上寫回被其他行程占用的檔案時 EPERM。
- 修正多項終端機輸入、控制結構、檔案傳輸、授權對話框被蓋住等問題。

## 已知限制

- 動畫簡報：中文旁白要先在設定啟用中文語音服務，否則只有字幕；英文旁白用本機模型，第一次要下載、一次只能合成一段；樣板還沒有編輯介面；離線小模型還不能做簡報；3D 頁的鏡頭運鏡與 MP4／PPTX 匯出的完整成品，只做過基本驗證。
- 網頁版的大型專案索引只用 OPFS 當作授權資料夾實測過（6000 個檔案）；7 萬到 50 萬檔的規模尚未實測。
- 網頁版的 `/mnt` 即時對應沒有用真實的資料夾選擇器完整驗證。
