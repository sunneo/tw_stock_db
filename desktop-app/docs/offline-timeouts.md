# 離線模型的耗時上限盤點與處理

使用者原話（2026-11-18）：「這不是線上的，這是離線，使用者的電腦 GPU，當使用者決定用離線模型，就有要等很久的準備了。」
原則：離線路徑不設固定耗時上限。只在三種情況中斷：明確失敗（載入錯誤、記憶體不足、超出長度上限）、退化文字（共用 `FaVlm.looksLikeGarbage`）、使用者取消。其餘只顯示進度。線上 API 的逾時不動。
